# Code of Conduct

This project adopts the **[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** by reference. Contributors, maintainers, and participants in this project's spaces (issues, pull requests, discussions) are expected to follow it.

## Reporting

Concerns about behavior in this project's spaces can be reported to the project maintainer at **[toujeni.cherif@gmail.com](mailto:toujeni.cherif@gmail.com)**. Reports will be reviewed promptly and treated as confidential to the extent reasonable.

## Enforcement

The project maintainer is responsible for applying and enforcing this code fairly. Actions may include warnings, temporary restrictions, or removal from the project's spaces, proportionate to the issue.
